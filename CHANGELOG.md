# Changelog

## v0.1.0

Initial public release.

- Show remaining 5-hour Codex usage in the macOS menu bar.
- Show remaining weekly Codex usage.
- Show compact reset countdowns, e.g. `4h25m` and `3d1h`.
- Show the current Codex model and reasoning effort in the dropdown menu.
- Refresh quota data every 60 seconds.
- Run entirely locally with no analytics, telemetry, ads, or project-owned server.
- Install as a menu-bar-only app with no Dock icon.
